# YOYO IPTV

Flutter starter project for an IPTV player targeting Android, Android TV, and iOS.

## Included in this starter
- Dark Material 3 interface
- Xtream Codes login form (server URL, username, password)
- Welcome screen with Live TV, Movies, TV Series, and Favorites sections
- HTTP and video-player dependencies ready for the next development stage

## Important
This is a UI starter. The Xtream Codes API integration, channel/movie/series loading,
player controls, and secure credential storage still need to be implemented.

## Run
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Build Android APK
`flutter build apk --release`
